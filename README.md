# Black Heart Dance House — Mobile Web Application

> Официальное мобильно-ориентированное веб-приложение студии современного танца и пилонного искусства **«Black Heart Dance House»** (г. Минск, ул. Притыцкого, 62/м, ст. м. Кунцевщина / Спортивная).

## О проекте
Данный проект разработан в рамках дисциплины **«Разработка мобильных приложений»** (Лабораторная работа № 6).  
Студентка: **Каменецкая Дарья**, группа **т-391**.

## Архитектура и функционал
- **Mobile First дизайн**: верстка оптимизирована под мобильные экраны (360–430px) с медиа-запросами для планшетов и десктопов;
- **Экран 1 (Главная / Каталог)**: интерактивный каталог направлений (Exotic Pole Dance, High Heels, Contemporary, Vogue, Hip-Hop), недельное расписание, калькулятор стоимости абонементов в белорусских рублях (BYN), онлайн-бронирование;
- **Экран 2 (Детализация)**: подробная страница направления Exotic Pole Dance с характеристиками тренировки, информацией о топ-тренере и фотогалереей зала;
- **Экран 3 (Личный кабинет)**: персональный профиль ученицы Дарьи Каменецкой, виртуальная клубная карта `#BH-391-DK`, баланс занятий, история визитов и динамический QR-код для турникета.

## Технологии
- HTML5, семантическая разметка
- CSS3 (Flexbox, CSS Custom Properties, @media queries, Reset/Normalize)
- Vanilla JavaScript (ES6+)
- React Native WebView (гибридная интеграция через Expo Snack)
